\chapter{TERMS OF PAYMENT}

\section{Fee Summary}
The total fixed price for the "Event Management \& Online Ticketing System" (Project ID: ITPJ2602) is set at \textbf{1,500,000,000 VNĐ} (One Billion Five Hundred Million Vietnamese Dong). This fee is inclusive of all personnel, software licenses, implementation, and initial cloud infrastructure setup required to meet the project objectives.

\section{Storage, Personnel, Training, Implementation Costs}
The total project fee is calculated based on the following primary cost drivers:
\begin{itemize}
    \item \textbf{Personnel:} A dedicated team of 5 members (Project Manager, Backend Developer, Frontend Developer, Mobile Developer, and QA/Tester) for a duration of 5 months.
    \item \textbf{Storage \& Cloud Infrastructure:} Initial provisioning of high-availability cloud servers (AWS/Google Cloud/Azure) capable of handling 10,000 concurrent users.
    \item \textbf{Training:} Training sessions for De De Startup’s internal staff on managing events, dynamic seating, and utilizing the mobile scanning module.
    \item \textbf{Implementation:} Deployment costs, CI/CD pipeline setup, and security auditing for the payment gateway.
\end{itemize}
