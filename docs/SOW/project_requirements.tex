\chapter{PROJECT REQUIREMENTS}

\section{Agency Responsibilities}
The Agency (Development Team) shall be responsible for the following:
\begin{itemize}
    \item Developing a high-performance Web Application and Mobile Module as specified in the Scope of Work.
    \item Ensuring the system can handle a minimum of 10,000 concurrent users and 50,000 tickets per event.
    \item Implementing security measures to prevent QR code duplication and bot attacks.
    \item Providing a simulated Payment Gateway environment for testing purposes.
    \item Conducting system training for the Client’s staff and delivering all technical documentation.
    \item Ensuring a system response time of less than 2 seconds and entry verification under 5 seconds.
\end{itemize}

\section{Client Responsibilities}
The Client (De De Startup) shall be responsible for the following:
\begin{itemize}
    \item Providing timely feedback on UI/UX designs and functional prototypes within 3 business days.
    \item Providing all necessary brand assets (logos, color schemes) and event data for system population.
    \item Assigning a dedicated Point of Contact (POC) for the Scrum team to participate in Sprint Reviews.
    \item Ensuring stable internet connectivity at event venues for the mobile scanning application.
    \item Performing User Acceptance Testing (UAT) according to the agreed-upon schedule.
\end{itemize}

\section{Mutual Responsibilities}
Both parties shall be responsible for:
\begin{itemize}
    \item Participating in weekly progress meetings and maintaining active communication via agreed channels (e.g., Zalo, Email).
    \item Identifying and escalating potential "Scope Creep" immediately to the Project Manager.
    \item Adhering to the Scrum framework to ensure iterative delivery and transparency.
\end{itemize}
