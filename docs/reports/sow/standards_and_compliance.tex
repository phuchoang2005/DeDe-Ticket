\chapter{STANDARDS AND COMPLIANCE}

\section{Communications Plan}
Effective communication will be maintained through the following channels:
\begin{itemize}
    \item \textbf{Daily Stand-ups:} 15-minute internal Scrum meetings to track progress.
    \item \textbf{Weekly Progress Review:} A formal meeting every Thursday between the Agency PM and De De Startup’s POC to review Sprint progress and handle blockers.
    \item \textbf{Primary Channels:} Zalo for instant communication; Email for formal approvals; Jira for task and bug tracking.
\end{itemize}

\section{Quality Management Plan}
To ensure the system meets the "Success Criteria" (10,000 CCU, < 2s response), the following measures will be applied:
\begin{itemize}
    \item \textbf{Code Reviews:} Peer review for all backend and mobile source code.
    \item \textbf{Automated Testing:} Unit tests for payment and QR generation logic.
    \item \textbf{Load Testing:} Simulated stress tests using JMeter/Locust to validate concurrency requirements.
    \item \textbf{User Acceptance Testing (UAT):} A 1-week period for the Client to verify all features against the SRS.
\end{itemize}

\section{Training Plan}
The Agency will provide two primary training sessions:
\begin{enumerate}
    \item \textbf{Admin Portal Training:} For De De Startup staff on event creation, seat mapping, and financial reporting.
    \item \textbf{On-site Operation Training:} For gate controllers on using the Mobile Scanning App, including offline mode handling.
\end{enumerate}

\section{Standard Compliance}
The project will adhere to:
\begin{itemize}
    \item \textbf{Web Standards:} W3C compliance for cross-browser compatibility (Firefox, Chrome, Safari).
    \item \textbf{API Standards:} RESTful API architecture for seamless integration between Web and Mobile.
\end{itemize}

\section{Regulatory Compliance}
The system will be developed in compliance with local regulations regarding:
\begin{itemize}
    \item \textbf{E-commerce Laws:} Following Vietnam's regulations on electronic transactions and online service provision.
    \item \textbf{Cybersecurity:} Adhering to national standards for information system security for startups.
\end{itemize}

\section{Privacy Adherence}
The Agency guarantees that:
\begin{itemize}
    \item All user personal data (Phone, Email, Identity) will be encrypted at rest.
    \item No third-party access to De De Startup's customer behavioral data is permitted.
    \item QR codes will be hashed using secure algorithms to prevent reverse-engineering.
\end{itemize}
