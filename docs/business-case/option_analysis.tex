\chapter{Options Analysis}
To address the critical failures in manual ticketing and the need for scalability, three primary options have been evaluated. This analysis considers the long-term strategic fit and the specific technical constraints (10,000 CCU, offline scanning) of Dề Dê Startup.

\section{Option 1: Do Nothing (Maintain Manual Process)}

This option involves continuing the current workflow of selling tickets via Facebook and manually verifying bank transfers.

\textbf{Description:} No financial investment in technology; maintain a team of admins to verify transactions manually.

\section{Option 2: Utilize Third-party SaaS (Ticketing Platforms)}

This option involves using existing platforms like Eventbrite or local providers.

\textbf{Description:} Outsourcing the ticketing infrastructure to a provider. Dề Dê pays a commission fee per ticket sold.

\section{Option 3: Custom Built System (Project ITPJ2602) - Preferred Option}

This option involves building a tailored Web and Mobile ecosystem specifically designed for high-concurrency and fraud prevention.

\textbf{Description:} A 5-month development project to create a proprietary platform owned entirely by Dề Dê.
